SlateboxJS v2 Demo

A modern diagramming library built with svg.js and Vite

How to Use:

  • Add Nodes: Click the buttons above to add different types of nodes
  • Drag Nodes: Click and drag any node to move it around
  • Lock/Unlock: Use the lock buttons to prevent or allow dragging
  • Clear: Remove all nodes from the slate

Features Demonstrated:

  • ✅ SVG-based drawing canvas
  • ✅ Draggable nodes with svg.draggable.js
  • ✅ Multiple node shapes (rectangle, circle, ellipse)
  • ✅ Node text rendering and positioning
  • ✅ Node locking/unlocking
  • ✅ Programmatic node creation and management
  • ✅ Invoker contract for external tool integration
