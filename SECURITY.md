# Security policy

SlateboxJS follows the security policy of the Slatebox project:
[Slatebox/slatebox SECURITY.md](https://github.com/Slatebox/slatebox/blob/main/SECURITY.md).

## Reporting a vulnerability

Please report security problems privately, never in a public issue, discussion or pull request.

- **Preferred:** a private report through GitHub:
  [Report a vulnerability](https://github.com/Slatebox/slateboxjs/security/advisories/new), or in
  the app repository: [Report a vulnerability](https://github.com/Slatebox/slatebox/security/advisories/new).
- **Or:** the contact form at https://slatebox.com/contact, starting the message with "Security".

Say what you found, how to reproduce it, and what it lets someone do.

## Supported versions

Security fixes go into the newest `slateboxjs` release on npm. Older versions are not patched;
upgrade with `npm install slateboxjs@latest`.
