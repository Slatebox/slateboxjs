# Archive

These are working notes from building SlateboxJS v3: hand-off prompts, loop prompts, the
productionization ledger, one-off runbooks and fix write-ups. They are kept for history and
are not maintained. Paths, sha references and status claims in them describe the day they
were written, and some name the repository's former name (slateboxjs-v2).

For current documentation, start with the [README](../../README.md),
[drop-in-contract.md](../drop-in-contract.md), [meteor-swap.md](../meteor-swap.md) and
[CONTRIBUTING.md](../../CONTRIBUTING.md).
