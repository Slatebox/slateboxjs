🎨 Visual Effects

  • Pan/Zoom Canvas: Mouse wheel to zoom, drag to pan
  • Resize Nodes: Click "Enable Resize" then click a node
  • Rotate Nodes: Click "Enable Rotate" then use rotation handle
  • Drag Nodes: Click and drag any node to move it
  • Multi-Select: Hold Ctrl and click multiple nodes
  • Zoom Controls: Use the controls in top-right corner

🚀 Quick Start:

  1. Add some nodes using the buttons
  2. Try panning and zooming the canvas
  3. Enable resize/rotate and click on a node
  4. Drag the handles to resize or rotate
  5. Use zoom controls to navigate large diagrams
